# 鸿蒙模型语音、耳机说话打断与图片选择恢复

## 模型语音

壳固定 `sherpa_onnx: 1.13.8`，匹配官方 `sherpa-onnx-v1.13.8-ohos-arm64-v8a.tar.bz2`。
`scripts/sherpa-native.json` 记录发布包和两个共享库的 SHA-256，准备脚本只安装通过校验的
ELF64 AArch64 库。原生库保存在忽略的 `ohos/entry/libs/arm64-v8a/`，新机器可复现下载。
离线准备可运行 `python3 scripts/prepare-sherpa.py /path/to/release.tar.bz2`。
`scripts/build-release.sh` 自动准备并验证 HAP 中的可加载段、AOT 和许可。

上游 Dart 加载器尚未识别 `ohos`，共享运行时在 OHOS 显式打开 C API 并初始化同一套
绑定，校验运行时版本后才创建模型。其他平台使用原加载器。模型下载、ZIP 校验、
Matcha manifest、用户音色及 WAV 缓存复用现有实现；模型不随 HAP 默认打包。
模型管理页开放下载和导入，目录副本导入后用原生方法释放，手机可用 ZIP。

AVPlayer 只打开 `cacheDir/tts_audio_cache/` 内的普通 WAV，不跟随最终路径符号链接，
文件须大于 44 字节且不超过 32 MiB；180 秒播放看门狗、错误和系统中断会报错。
播放完成、停止、后台和 engine 销毁均释放播放器、描述符及等待结果。旧请求的 stop
不能停止新播放，播放器异步创建期间的取消也不会迟到开始播放。

官方 TTS 库包含 eSpeak NG（GPLv3）。`assets/licenses/` 保留完整许可、ONNX Runtime
第三方声明和对应源码链接，并注册到应用许可列表；发布分发应满足这些组件的许可义务。
本次未修改上游二进制。官方构建脚本和发布见：
https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/build-ohos-arm64-v8a.sh
https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.8

## 耳机模式

`VoiceAudioPlugin` 实现现有 `aipu/voice-audio` 协议，使用 API 21 音频会话与输入选择接口。
只拥有本次激活的会话，释放时恢复之前的输入选择并退出通信场景。
准备时校验识别输入、通信输出和媒体输出的首选路由：三者都必须是有线带麦、USB 耳机
或蓝牙 SCO。仅 A2DP、无麦耳机、扬声器、选择失败或路由不明时返回 `safeDuplex=false`。
原有 UI 会回退到轮流收音/播报及按钮打断。

设备变化、会话失效或系统要求暂停/停止时，立即撤销安全状态、停止识别与系统/模型播放。
Dart 每 200 ms 校验路由，断线后暂停当前请求，需用户确认环境后继续；后台也释放会话。
这不承诺所有蓝牙耳机均可双工，也没有将系统首选路由检测当作实际回声隔离的真机证据。

## 选择期间进程恢复

打开系统相册/相机前，将原输入和已有图片记录在应用 `filesDir`；每张图片完成沙箱复制后
原子更新记录并 fsync，返回 Flutter 前标记 ready。记录只包含本应用的沙箱副本，
不把系统 provider URI 当成永久授权文件路径。

恢复按账号/已保存会话隔离。未保存的新会话没有稳定 cid，使用账号/助手/项目作用域，
再次新建同类会话可恢复。文件名为作用域 SHA-256；其他作用域和无作用域的通用
`getLostData` 调用不能读取该记录。记录最多 1 MiB，24 小时后在访问时过期；缓存被系统
清理、文件不存在、路径越界、链接和超限文件不会回传为可恢复图片。

重新进入输入框会提示恢复或丢弃。恢复追加图片，保留当前非空输入，不自动发送；
确认后以操作 id 删除记录，重复或过期确认不能消费更新的记录。切换账号、会话、编辑锁
或输入内容变化时拒绝迟到回填。正常选择结果被输入框处理后同样确认该记录。

系统相册/相机的 Promise 尚未返回时，进程被终止后无法重建系统回调；此时恢复原输入、
已有图片和已完成复制的部分，并明确提示重新选择剩余图片。它不恢复整个应用导航栈、
已经确认回填后的常规草稿、流式请求或后台录音，也不会自动重新启动麦克风。

## 验证范围

原生测试执行真实 ArkTS 方法体，系统 API 使用替身；Flutter 测试验证播放等待、错误、
确认恢复、保留新输入、账号切换和原有语音插话。本次另核对 126 个 Dart C API 所需符号
均由官方 OHOS 库导出；构建检查独立 AOT 与 HAP 内容一致。上述检查不能替代鸿蒙真机加载与录音。

真机验收：下载/ZIP 导入 Baker 后关闭网络朗读；长文合成时取消、后台/重开、观察内存和
性能；分别使用有线、USB、SCO 与 A2DP 耳机，验证边播边说、连续插话、拔出、来电和
重连；在系统选择器打开、复制中和回调确认前终止进程，再打开原会话恢复/丢弃并切换账号。
