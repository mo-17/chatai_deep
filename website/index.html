一些你可能想知道的事

开始之前。

一定要注册账号才能使用吗？＋

可以先从登录页的游客模式进入，使用本地功能并连接自己的模型服务。官方试用、云同步和意见反馈需要登录；邮箱验证码注册、登录与找回密码已开放。

安装以后就能直接和 AI 聊天吗？＋

登录后进入「我的 → 官方试用与用量」，点击开始官方试用，无需填写自己的 Key。当前试用为 DeepSeek V4.1 Flash，支持文字聊天，每人每天 10,000 Token，UTC 0 点重置，输入、输出与思考均计入；另有全站额度与并发限制，以客户端显示为准。也可以在「AI 服务设置」使用自己的服务商与 API Key。

对话和文件会发送到哪里？＋

对话在客户端本地管理；发起 AI 请求时，相关对话内容和选中的附件会发送给你选择的模型服务。使用后端代理时，请求也会经过后端。敏感资料请先确认服务商的数据政策。

为什么目前只提供 Android 体验版？＋

当前可下载的是已构建的 Android 测试安装包。其它平台仍需完成发布签名及设备验收，暂不提供下载。本页会明确标注每个平台的实际发布状态。
