# 对话界面跟随聊天套装

在「我的 → 外观与主题 → 聊天装扮」开启「对话界面跟随套装」，选用插画套装后，聊天背景、顶部栏和输入框使用配套颜色；背景叠加淡化的静态套装图案。装扮页同时展示背景、消息、顶部区域和输入区的预览。

也可从任意对话的「更多 → 聊天装扮」直接进入，设置后返回当前对话立即生效，保留草稿与输入状态。

## 配置规则

- 页面跟随最近应用的整套装扮或最近选择的插画气泡。我的消息与 AI 回复的气泡、头像框仍独立保存；修改页面配色不会重置消息装扮、头像尺寸或间距。
- 新增 `chat_follow_decoration_v1` 开关键及 `chat_conversation_decoration_v1` 套装名，随现有主题配置保存。旧配置没有页面套装时，先沿用我的消息插画气泡，再回退 AI 插画气泡。未知名字安全回退。
- 关闭联动会恢复原对话页界面，保留最近套装供重新开启；「恢复默认」清除消息及页面装扮配置，保留全局风格、强调色和头像显示开关。
- 作用域仅覆盖对话页与装扮预览，不修改应用全局主题、字体、模型设置、发送参数或会话数据。其他聊天输入组件只有位于此作用域内才使用配套材质。

## 实现边界

- `ConversationDecorationTheme` 从套装 accent 与当前明暗模式生成不透明底色、面板、输入框和符合对比度的语义色。发送和停止按钮分别使用 `onPrimary` / `onError`，角色副标题跟随 `onSurfaceVariant`。
- `ConversationDecorationScope` 提供局部 ThemeData；真实对话页的顶部栏、消息列表和输入组件都从作用域内的 context 读取颜色。全局 AppVisualTheme 和字体保持原配置。
- `ConversationDecorationBackdrop` 使用静态封面及原生渐层；IgnorePointer、ExcludeSemantics、RepaintBoundary 将背景与消息交互和重绘隔离，不加入新的动画定时器。已有头像框、气泡动画继续按原有规则播放与暂停。
- 开关前后保持相同的 Theme、背景 Stack 和聊天内容结构，避免换装重建输入框状态或丢失草稿；不重置聊天列表的滚动控制器。
