# 真机 PDF 修复补丁归档

首轮 Git 整理只获准提交真机修复，扫描/导出模块在当时已存在但尚未跟踪；为避免混入此前功能，先归档精确补丁。

用户随后授权将剩余改动按功能分类提交。完整扫描/导出模块、回归与两份原生集成测试已进入 OCR 客户端批次 `19a302e5`。当前源码已经包含本补丁的修复，**不要重复应用**。

- `landscape-fixes.patch` 保存两处 PDF 页面方向修复，以及横页/竖页/方形页的两项回归。
- `native-ocr-tests.patch` 保存本次原生中文 OCR 与统一 smoke 测试入口的创建差异。
- `landscape-fixes-manifest.json` 保存原修复前后完整文件 SHA-256；当前三个生产/测试文件应匹配 postimage。

这些补丁保留为首轮隔离提交的审计记录。若需要移植到其他分支，应先匹配 preimage，再执行 `git apply --check`；已有 postimage 的分支无需应用。补丁已通过临时副本反向/正向应用与哈希校验。

原真机验收对应当时混合工作区；后续功能提交不代表重新完成所有平台真机验收。范围见 [真机记录](../android-device-debug-20261021.md) 和 [剩余改动分类](../remaining-changes-20261021.md)。
